# UI reference

Layout mirrors FL's functional arrangement; visuals are original (teal accent on slate).

- **Top:** menu bar (FILE EDIT ADD PATTERNS VIEW OPTIONS HELP) + toolbar: SONG/PAT, play,
  stop, record, BPM, song position (bar:beat:tick), metronome, typing keyboard, pattern
  selector, snap, CPU (real callback load + peak), master meter, no-audio warning.
- **Workspace:** floating windows (Channel rack, Piano roll, Mixer, instrument editors,
  Playlist/Browser placeholders, dialogs). Clicking a window gives it keyboard focus; the
  hint bar shows the focused context.
- **Bottom hint bar:** focus context, status messages, output device + latency, unsaved flag.
- Theme tokens: `crates/soundesti-app/src/theme.rs`. Window docking, workspace layouts,
  multi-monitor, theme switching: PLANNED (Phase 11).

## App icon
Original artwork generated by `scripts\make-icon.ps1` → `assets/icons/soundesti.ico` (16–256 px)
and `soundesti-<size>.png`: a white eighth note inside a glowing eight-point crystal (a teal
diamond frame over a violet square, inspired by floating "end crystal"-style gems) on a dark
rounded square. Embedded as the exe icon of `soundesti.exe` and the Installer Wizard
(`build.rs` + winresource), and as the window/taskbar icon. Re-run the script after design changes.

Screenshots of milestones are taken with `scripts\screenshot.ps1` (not committed; describe results in PROGRESS.md).
