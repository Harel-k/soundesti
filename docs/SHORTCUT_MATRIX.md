- **SM-1 Numpad:** egui reports numpad digits as main-row digits, so `Num...` bindings cannot fire yet (KI-002). They are BLOCKED, not remapped, to keep this profile faithful.
- **SM-2 Left/right modifiers:** FL uses Left-Shift vs Right-Shift and Right-Alt for some mouse gestures. Not distinguishable yet (KI-002).
- **SM-3 Quick quantize:** the manual lists `Ctrl/Cmd+Opt+Q`; the master prompt lists `Ctrl+Q`. Both are bound to Quick quantize.
- **SM-4 Playlist 5-9:** the manual does not say numpad; bound to the main digit row.
- **SM-5 Typing keyboard layout:** standard two-row tracker layout (Z-row lower octave, Q-row upper). Exact FL layout not yet verified.
- **SM-6 Text fields:** while a text field has focus only F1-F12 dispatch; everything else types. **Typing keyboard on:** single keys that are piano keys play notes; Space, F-keys, arrows and Ctrl/Alt chords still dispatch.
